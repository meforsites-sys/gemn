# English 6th Prep 2027 — إنشاء ملف APK عبر GitHub

## ملاحظة مهمة جداً عند الرفع
ارفع **محتويات هذا المجلد مباشرةً** إلى المستودع (ولا تضع مجلداً إضافياً فوقها).
إذا ظهر لك في تبويب **Actions** اسم **Build Android APK** فهذا هو المسار الصحيح لبناء ملف الـ APK (وليس Jekyll).

## خطوات الحصول على ملف APK بسهولة:
1. أنشئ مستودعاً جديداً في GitHub.
2. ارفع كل الملفات والمجلدات الموجودة داخل الحزمة إلى المستودع عبر **Add file -> Upload files**.
3. ادخل إلى تبويب **Actions** في المستودع واختر **Build Android APK** ثم اضغط **Run workflow** (أو انتظر البدء التلقائي بعد الرفع).
4. بعد انتهاء العملية بنجاح (علامة خضراء)، اضغط عليها وانزل إلى **Artifacts** لتحميل ملف الـ APK باسم `English-6th-Prep-2027-APK`.

## أمر إنشاء ملف APK محلياً:
```bash
./gradlew assembleDebug
```
